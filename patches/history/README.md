# Patch history

One-off scripts used to apply changes to the Lynx source, kept for the
reasoning they carry rather than for re-use: several comments in
`lynx_app.py`, `lynx_overlay.py`, `lynx_hdhomerun.py` and
`lynx_start.sh` point here with "see patch_<name>.py" when explaining
why a piece of code is the way it is.

Nothing in this folder runs as part of Lynx, and nothing imports it.
